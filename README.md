# House Viewing Inspector

Simple mobile-first inspection app for the Tonstall Road viewing.

## GitHub Pages
1. Create a new GitHub repository, e.g. `house-viewing-inspector`.
2. Upload all files in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. Open the generated GitHub Pages URL on your iPhone.
7. In Safari: Share → **Add to Home Screen**.

Data and photos are stored locally in the browser on the device. Export the inspection JSON after the viewing as a backup.
